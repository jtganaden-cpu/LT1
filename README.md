# School Circular Garden Information

## Description
- Developing a python program to help determine information about the garden based on the radius input by the user.

## How to Run 
1) Enter your chosen radius
2) All information will be immediately uploaded

## Input Needed
- radius in meters

## Sample Output
Enter radius in meters: 8

Area of the garden: 201.06 square meters

Circumference of the garden: 50.27 square meters

Square Root of Area: 14.18

Area Rounded Down: 201 square meters

Area Rounded Up: 202 square meters
